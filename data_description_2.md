# Data description - Project 2
The key variables are shots_on_goal, prior_average_shots, opponent_prior_avg_shots_against, shots_against, and homeRoad.
### Conceptualization and Operationalization of variables
The primary dependent variable in this project is shots_on_goal. Home and road for this context indicates whether an NHL season is playing at their own arena or at the other teams'. It is used by relabeling 'H' and 'R' which are found in each game row.
